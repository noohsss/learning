## 큐(Queue)

- 먼저 들어온 데이터가 먼저 나가는 자료구조
- `FIFO(First In, First Out)` 방식
- 한쪽에서는 삽입하고 반대쪽에서는 삭제한다.

```text
입력 → [ 1, 2, 3 ] → 출력
        먼저 들어온 1부터 나감
```

## 스택(Stack)

- 가장 나중에 들어온 데이터가 먼저 나가는 자료구조
- `LIFO(Last In, First Out)` 방식
- 한쪽에서 삽입과 삭제가 모두 이루어진다.

```text
입력 → [ 1, 2, 3 ] → 출력
        가장 나중에 들어온 3부터 나감
```

## deque

`deque`는 양쪽 끝에서 데이터를 삽입하고 삭제할 수 있는 자료구조다.

```python
from collections import deque

dq = deque()

dq.append(1)       # 오른쪽에 삽입
dq.appendleft(2)   # 왼쪽에 삽입
dq.pop()           # 오른쪽에서 삭제
dq.popleft()       # 왼쪽에서 삭제
```

### 큐와 스택 구현하기

```python
from collections import deque

# 큐: 오른쪽에 넣고 왼쪽에서 뺀다.
queue = deque([1, 2, 3])
queue.append(4)
print(queue.popleft())  # 1

# 스택: 오른쪽에 넣고 오른쪽에서 뺀다.
stack = deque([1, 2, 3])
stack.append(4)
print(stack.pop())  # 4
```

파이썬 리스트에서 `pop(0)`을 사용하면 앞의 데이터를 삭제한 뒤 나머지 데이터를 한 칸씩 이동해야 한다.  
따라서 큐를 구현할 때는 `popleft()`를 사용할 수 있는 `deque`가 더 적합하다.

## Array List와 Linked List

| 구분           | Array List       | Linked List                  |
| -------------- | ---------------- | ---------------------------- |
| 데이터 저장    | 연속된 공간      | 노드가 연결된 형태           |
| 인덱스 접근    | 빠름             | 느림                         |
| 중간 삽입·삭제 | 데이터 이동 필요 | 연결 변경                    |
| 파이썬 예시    | `list`           | 직접 구현하거나 `deque` 활용 |

## 정리

- 큐는 `FIFO`, 스택은 `LIFO` 방식이다.
- 리스트는 스택 구현에 사용할 수 있다.
- `deque`는 큐와 스택을 모두 구현하기 좋다.
- 큐에서 앞의 데이터를 삭제할 때는 `list.pop(0)`보다 `deque.popleft()`가 효율적이다.
- Array List는 인덱스 접근에 유리하고, Linked List는 삽입과 삭제에 유리하다.
