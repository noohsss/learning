## 컨테이너 자료형(Container)

- 여러 데이터를 한 곳에 저장할 수 있는 자료형
- 각각 순서와 변경 가능성에 따라 다르게 분류

### 순서에 따른 분류

- 순서가 있는 컨테이너 (Sequence): 데이터를 연속된 공간에 순서대로 저장하는 컨테이너 (ex: 리스트, 문자열, 레인지, 튜플)
- 순서가 없는 컨테이너 (Non-sequence): 데이터를 무작위의 순서로 저장하는 컨테이너 (ex: 집합, 딕셔너리)

### 변경 가능성에 따른 분류

- 변경 가능한 컨테이너 (Mutable): 생성된 이후, 값을 삽입/수정/삭제 할 수 있는 컨테이너 (ex: 리스트, 집합, 딕셔너리)
- 변경 불가능한 컨테이너 (Immutable): 생성된 이후, 값을 삽입/수정/삭제 할 수 없는 컨테이너 (exL 문자열, 레인지, 튜플)

## 리스트(List)

- 0개 이상의 값을 순서 있게 저장하는 컨테이너 자료형
- 파이썬에서는 리스트 안에 다양한 자료형을 저장할 수 있다.

## 리스트 연산

- 리스트는 덧셈(`+`)과 곱셈(`*`) 연산을 제공

```python
data = [10, 1.5, "python", False]
print(data)
```

## 인덱싱(indexing)

- 리스트의 특정 원소가 몇 번째에 위치하는지 나타내는 숫자
- 파이썬은 음수 인덱싱도 가능, 인덱스를 뒤에서 부터 세는 것을 의미(맨 뒤의 인덱스는 -1로 시작)

## 슬라이싱(slicing)

- 리스트의 특정 구간을 나누어 자르는 것
- `start`: 리스트를 자를 범위의 시작 인덱스
- `end`: 리스트를 자를 범위의 끝 인덱스 (end 인덱스의 원소는 포함하지 않음)
- `step`: 리스트를 얼마 간격으로 뛰어넘으며 자를 것인지 결정 (음수는 반대 방향)

## 리스트의 삽입과 삭제

- `append()`: 맨 마지막에 새로운 원소를 삽입
- `pop()`: 맨 마지막 원소를 삭제 or 특정 인덱스의 원소를 삭제

## 리스트 컴프리헨션(List Comprehension)

- [변수 for 변수 in 리스트로 작성]

```python
# 일반적인 초기화
numbers = []
for i in range(1, 11):
    numbers.append(i)
print(numbers)

# 리스트 컴프리헨션을 이용한 초기화
numbers = [i for i in range(1, 11)]
print(numbers)

# 조건문을 이용한 필터링
even_numbers = [i for i in range(1, 11) if i % 2 == 0]
print(even_numbers)
```

## 자주 사용하는 리스트 메서드

- `insert()`: 인덱스에 해당하는 위치에 새로운 원소 삽입
- `extend()`: 리스트의 끝에 새로운 리스트를 이어 붙힘
- `remove()`: 리스트에서 해당 원소를 삭제. (중복 시 가장 앞쪽 원소 삭제)
- `count()`: 원소의 개수를 카운트
- `index()`: 원소가 존재하는 인덱스를 반환
- `sort()`: 정렬 (reverse=True 시 순서 반대)
- `reverse()`: 순서를 뒤집는다.

## 반복문(loop)

### for

```python
for i in range(10): # 0 ~ 9까지 반복
    print(i)    # 0 ~ 9까지 출력
```

- 반복 횟수가 정해져 있는 경우 사용
- for문에서 정의한 변수를 사용하지 않을 때는 변수 명보단 `_`로 정의한다.(중요하지는 않음.)

### while

```python
i = 0

while i < 4: # 조건

    print(i)
    i += 1 # 증감식
```

- 반복 횟수가 정해져 있지 않은 경우 사용 (사용자가 반복 횟수를 조절 가능)
- 반복 횟수는 조건문의 True, False로 판단(True면 반복, False는 종료)
- 증감식을 작성하지 않으면 무한 루프에 빠질 수 있다.

### break/continue

```python
i = 1

while True:
    print(i)

    # i가 3일 때, 반복 종료
    if i == 3:
        print("반복을 종료합니다.")
        break

    i += 1
```

- break: 반복문을 강제 종료. for 문과 while 문 모두 사용 가능. 특정 조건을 만족 했을때 반복을 종료

```python
i = 1

while i <= 10:
    if i % 2 == 0:  # 만약 i가 짝수라면
        i += 1
        continue  # 아래를 실행하지 않고 다음 반복으로 넘어감

    print(i)  # 홀수만 출력
    i += 1
```

- continue: 다음 반복으로 강제 이동. for 문과 while 문에서 모두 사용 가능. 특정 조건 만족 시 아래 부분을 실행하지 않고, 다음 반복으로 넘긴다.

## 오늘 배운 내장함수 및 문법

- `id()`: 파이썬 객체의 고유값(주소값)을 반환
- `len()`: 리스트의 길이를 구해준다.(자바의 length()와 같음)
- `append()`: 리스트안에 새로운 요소를 추가
- `range()`: 수열을 생성하는 자료형 (ex: range(10) -> 0 ~ 9까지, range(1, 10) -> 1 ~ 9까지, range(1, 1, 10) 1 ~ 9까지 1씩 증가)
- `f-String`: 문자열 사이에 변수를 넣을 수 있다.(ex: f"반가워요, {name}님")
