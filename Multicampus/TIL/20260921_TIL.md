## Fault Tolerance

### 실습: 재시도 후 실패 결과 남기기

외부 조회 서비스가 계속 연결되지 않는 상황을 가정한다. `RetryPolicy`로 세 번까지 재시도하고, 모두 실패하면 `error_handler`가 실패 상태와 오류 메시지를 State에 기록한 뒤 `finalize`로 이동한다.

실습 코드는 앞에서 정의한 `RetryState`, `RetryPolicy`, `StateGraph` 등의 환경을 그대로 사용한다. `call_service`가 실패하면 `error_handler`가 실행되고, `Command`의 `update`로 State를 변경하면서 `finalize`를 다음 Node로 지정한다.

```python
from langgraph.errors import NodeError


class State(TypedDict):
    status: str
    error_message: str



def practice_call_service(state):
    print(f"조회 시도 - 연결 실패")
    raise ConnectionError("외부 조회 서비스 연결 실패")


def service_error_handler(state: State, error: NodeError) -> Command:
    print("error_handler 실행: 실패 상태를 기록하고 finalize로 이동")
    return Command(
        update={"status": "failed", "error_message": f"{error.node}: {error.error}"},
        goto="finalize",
    )


def finalize(state: State):
    print(f"finalize 실행: status={state['status']}, error_message={state['error_message']}")
    return {"status": state["status"], "error_message": state["error_message"]}


retry_policy = RetryPolicy(
    initial_interval=1.0, backoff_factor=2.0, max_interval=1.0,
    max_attempts=3, jitter=True, retry_on=ConnectionError,
)

retry_builder = StateGraph(RetryState)
retry_builder.add_node("call_service", practice_call_service, retry_policy=retry_policy, error_handler=service_error_handler)
retry_builder.add_node("finalize", finalize)

retry_builder.add_edge(START, "call_service")
retry_builder.add_edge("call_service", "finalize")
retry_builder.add_edge("finalize", END)
retry_graph = retry_builder.compile()

display(Image(retry_graph.get_graph().draw_mermaid_png()))
```

## Agent Tool 실행 검증과 통제

### 실습: Context로 Tool 실행 허용하기

실행 Context의 `allow_tool` 값에 따라 Tool 실행 여부를 결정한다. `True`이면 `get_notice`가 실행되고, `False`이면 Middleware가 `handler`를 호출하지 않아 Tool 실행을 차단한 뒤 거절 사유를 ToolMessage로 전달한다.

```python
@tool
def get_notice() -> str:
    """안내 문구를 조회한다."""
    print("Tool 실행")
    return "오늘 수업은 오후 6시에 시작합니다."

@wrap_tool_call
def validate_permission(request: ToolCallRequest, handler):
    print("실행 전 검사: ", request.tool_call["name"])

    if not request.runtime.context.get("allow_tool", False):
        error = failure("FORBIDDEN", "이 Tool을 실행할 권한이 없습니다.")
        return ToolMessage(
            content=json.dumps(error, ensure_ascii=False),
            tool_call_id=request.tool_call["id"],
            name=request.tool_call["name"],
            status="error",
        )

    print("Tool 실행: ", request.tool_call["name"])
    return handler(request)


notice_system_prompt = (
    "사용자가 안내 문구를 요청하면 get_notice Tool을 호출하세요."
    "오류가 있으면 사유를 안내하고 안내 문구를 추측하지 마세요."
)

notice_agent = create_agent(
    model=llm,
    tools=[get_notice],
    system_prompt=notice_system_prompt,
    middleware=[validate_permission],
)
```

Middleware는 Tool 호출 전 Context를 확인하고, 권한이 있는 경우에만 `handler(request)`를 호출한다. 권한이 없는 경우에는 실제 함수 본문에 진입하지 않으므로 `Tool 실행` 문구도 출력되지 않는다.

```python
# allow_tool=True: 실행이 허용되어 안내 문구를 조회한다.
result = notice_agent.invoke(
    {"messages": [HumanMessage(content="오늘 수업 안내 문구를 알려줘.")]},
    context={"allow_tool": True},
)

for message in result["messages"]:
    message.pretty_print()
```

`allow_tool=True`인 경우 실행 전 검사를 통과하고 안내 문구를 반환한다.

```python
# allow_tool=False: 실행이 차단되어 Tool을 호출하지 않고 거절 사유를 안내한다.
result = notice_agent.invoke(
    {"messages": [HumanMessage(content="오늘 수업 안내 문구를 알려줘.")]},
    context={"allow_tool": False},
)

for message in result["messages"]:
    message.pretty_print()
```

`allow_tool=False`인 경우 `FORBIDDEN` 오류가 전달되고 Tool 함수는 실행되지 않는다.
