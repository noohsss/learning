## Scope(스코프)

- 변수가 접근 가능한 범위
- 함수 내부에서 만든 변수는 함수 외부에서 사용할 수 없다.
- 파이썬의 `if`, `for`문은 별도의 block scope를 만들지 않는다.

```python
def func():
    value = 10
    print(value)  # 함수 내부에서는 접근 가능

func()
# print(value)  # 함수 외부에서는 접근 불가
```

## LEGB Rule

변수를 찾을 때 다음 순서로 탐색한다.

1. **Local**: 현재 함수 내부
2. **Enclosed**: 중첩 함수의 바깥 함수 내부
3. **Global**: 현재 파일의 전역 영역
4. **Built-in**: 파이썬 기본 내장 영역

### Global 변수 사용

함수 외부의 변수는 함수 내부에서 읽을 수 있다.

```python
value = 30

def func():
    print(value)

func()  # 30
```

함수 내부에서 같은 이름으로 변수를 만들면 함수 내부의 Local 변수가 우선한다.

```python
value = 50

def func():
    value = 500
    print(value)  # 500

func()
print(value)  # 50
```

### Enclosed 변수

중첩 함수에서는 바깥 함수의 변수를 사용할 수 있다.

```python
def outer():
    value = 40

    def inner():
        print(value)

    inner()

outer()  # 40
```

### global 키워드

`global`을 사용하면 함수 내부에서 전역 변수의 값을 변경할 수 있다.

```python
value = 60

def func():
    global value
    value = 600

func()
print(value)  # 600
```

- 알고리즘 문제에서는 사용할 수 있지만, 개발할 때는 전역 변수 변경을 피하는 것이 좋다.

## if, for문의 변수 범위

파이썬에서는 `if`, `for`문 안에서 만든 변수를 문 밖에서도 사용할 수 있다.

```python
if True:
    value = 30

print(value)  # 30
```

## DP(Dynamic Programming)

- 큰 문제를 작은 문제로 나누어 해결하고, 이미 계산한 결과를 저장해 재사용하는 알고리즘 기법
- 같은 작은 문제가 반복해서 나타날 때 사용한다.
- 한 번 계산한 결과를 저장해 중복 계산을 줄인다.
- 점화식과 초기값을 정하는 것이 중요하다.

## 시간복잡도

- 입력 크기(n)가 증가할 때 알고리즘의 연산량이 얼마나 증가하는지를 표현
- 실제 실행 시간보다 입력 크기에 따른 증가율을 비교한다.
- 보통 가장 큰 영향을 주는 반복문이나 연산을 기준으로 판단한다.
- 상수와 작은 항은 제외하고 Big-O 표기법으로 나타낸다.

### 자주 사용하는 시간 복잡도

| 시간 복잡도  | 예시                    | 특징                               |
| ------------ | ----------------------- | ---------------------------------- |
| `O(1)`       | 리스트 인덱스로 값 접근 | 입력 크기와 상관없이 일정          |
| `O(log n)`   | 이진 탐색               | 탐색 범위를 절반씩 줄임            |
| `O(n)`       | 리스트 전체 탐색        | 입력 크기에 비례                   |
| `O(n log n)` | 효율적인 정렬           | 정렬에서 자주 등장                 |
| `O(n²)`      | 이중 반복문, 버블 정렬  | 입력이 커지면 연산량이 빠르게 증가 |
| `O(2ⁿ)`      | 단순 재귀 피보나치      | 입력이 조금만 커져도 매우 느려짐   |
