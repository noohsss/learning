## Debugger(w. vscode)

### 디버깅 순서

1. 오류 메시지와 발생 위치 확인
2. 문제가 생긴 코드까지 실행 흐름 확인
3. 변수 값 확인
4. 원인 수정 후 다시 실행

### Break Point

VS Code에서 코드 줄 번호 왼쪽을 클릭하면 중단점을 만들 수 있다.
실행 중 해당 줄에서 멈추고 변수 값을 확인할 수 있다.

- **Continue**: 다음 중단점까지 실행
- **Step Over**: 현재 줄 실행 후 다음 줄로 이동
- **Step Into**: 함수 내부로 들어가기
- **Step Out**: 현재 함수에서 빠져나오기

`F5`로 디버깅을 시작하고, `Shift + F5`로 종료한다.

## `*args`, `**kwargs`

- `*args`: 여러 위치 인자를 튜플로 받음
- `**kwargs`: 여러 키워드 인자를 딕셔너리로 받음

```python
def show_info(*args, **kwargs):
    print(args)
    print(kwargs)

show_info(10, 20, name="철수")
```

## 패킹과 언패킹

- 패킹: 여러 값을 하나로 묶기
- 언패킹: 묶인 값을 다시 펼치기
- 함수 호출에서 `*`는 리스트·튜플, `**`는 딕셔너리를 펼침

```python
def add(x, y):
    return x + y

values = [10, 20]
print(add(*values))

user = {"name": "영희", "age": 20}
```

## 얕은 복사와 깊은 복사

`b = a`는 복사가 아니라 같은 리스트를 가리키는 것.

- 얕은 복사: 바깥 객체만 복사하고 내부 객체는 공유
- 깊은 복사: 내부 객체까지 모두 복사

```python
import copy

original = [[1, 2], [3, 4]]
shallow = original.copy()
deep = copy.deepcopy(original)
```

## `with` 문

파일을 다 쓴 뒤 자동으로 닫아 준다. 오류가 나도 정리된다.

```python
with open("example.txt", "w", encoding="utf-8") as file:
    file.write("안녕하세요")
```

## `__str__`과 `__repr__`

- `__str__`: 사용자가 보기 좋은 문자열. `print()`에서 사용
- `__repr__`: 개발자가 객체를 확인하기 위한 표현

## `is`와 `==`

- `==`: 값 비교
- `is`: 같은 객체인지 비교
- `None` 비교는 `is None` 사용

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)  # True
print(a is b)  # False
print(a is c)  # True
```

## 제네릭

하나의 함수나 클래스를 여러 자료형에 사용할 때 사용한다.

```python
from typing import TypeVar

T = TypeVar("T")

def get_first(items: list[T]) -> T:
    return items[0]
```

## 덕 타이핑과 `Protocol`

객체의 종류보다 필요한 기능이 있는지를 보는 방식이다.
`Protocol`로 필요한 메서드를 타입 힌트에 적을 수 있다.

```python
from typing import Protocol

class Speaker(Protocol):
    def speak(self) -> str:
        pass

class Dog:
    def speak(self) -> str:
        return "멍멍"

def make_sound(animal: Speaker):
    print(animal.speak())
```

ABC처럼 부모 클래스를 꼭 상속하지 않아도 된다. 필요한 메서드만 있으면 사용할 수 있어 결합도가 낮다.

## 제너레이터

`yield`를 사용해 값을 한 번에 만들지 않고 필요할 때 하나씩 만든다.

```python
def simple_generator():
    yield "A"
    yield "B"
    yield "C"

for value in simple_generator():
    print(value)
```

- 메모리를 적게 사용
- 큰 파일이나 스트리밍 데이터 처리에 적합
- `next()`를 호출할 때마다 다음 `yield`까지 실행
- 데이터가 작고 여러 번 사용할 때는 리스트가 편리

## Pydantic 데이터 모델

Pydantic은 타입 힌트로 데이터 구조를 만들고 값을 검증하는 라이브러리다.
입력 데이터가 정해진 형식에 맞는지 확인할 때 사용한다.

```python
from typing import Literal
from pydantic import BaseModel, Field

class User(BaseModel):
    name: str
    age: int = Field(ge=0, le=120)
    status: Literal["active", "inactive"]

user = User(name="철수", age=25, status="active")
```

- `Literal`: 정해진 값만 허용
- `Field`: 범위, 길이, 개수 등의 조건 설정
- 조건에 맞지 않으면 `ValidationError` 발생

### 데이터 변환과 검증

```python
from pydantic import ValidationError

data = {"name": "영희", "age": 20, "status": "inactive"}

try:
    user = User.model_validate(data)
except ValidationError as error:
    print(error.errors())
else:
    print(user.name)
    print(user.model_dump())
```

JSON 문자열은 `model_validate_json()`으로 검증할 수 있다.
