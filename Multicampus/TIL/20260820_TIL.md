## Exception Handling(예외 처리)

예외(exception)는 프로그램 실행 중 발생하는 오류다. 예외 처리를 사용하면 오류가 발생해도 프로그램이 바로 종료되지 않게 할 수 있다.

### try - except

예외가 발생할 수 있는 코드는 `try`에 넣고, 예외가 발생하면 `except`가 처리한다.

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다.")
```

예외 종류를 적어 두면 원하는 예외만 처리할 수 있다. `except:`로 모든 예외를 잡기보다 구체적인 예외를 지정하는 편이 좋다.

```python
try:
    number = int(input())
    result = 10 / number
except ValueError:
    print("숫자로 변환할 수 없습니다.")
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다.")
```

`as`를 사용하면 예외 객체를 변수로 받아 오류 메시지를 확인할 수 있다.

```python
try:
    result = 10 / 0
except ZeroDivisionError as error:
    print(error)
```

### raise

`raise`는 조건에 맞지 않을 때 예외를 직접 발생시키는 데 사용한다.

```python
def check_age(age):
    if age < 0:
        raise ValueError("나이는 음수일 수 없습니다.")
    return age

try:
    check_age(-5)
except ValueError as error:
    print(error)
```

### else와 finally

- `else`: `try`에서 예외가 발생하지 않았을 때만 실행된다.
- `finally`: 예외 발생 여부와 관계없이 항상 실행된다. 파일이나 네트워크 자원을 정리할 때 활용한다.

```python
def divide_data(value):
    try:
        result = 100 / int(value)
    except ValueError:
        print("숫자 형태의 문자가 아닙니다.")
    except ZeroDivisionError:
        print("0으로 나눌 수 없습니다.")
    else:
        print(f"연산 결과: {result}")
    finally:
        print("데이터 처리를 완료했습니다.")
```

### 사용자 정의 예외

`Exception` 클래스를 상속하면 필요한 예외 클래스를 직접 만들 수 있다.

```python
class MyCustomError(Exception):
    pass

try:
    raise MyCustomError("사용자 정의 오류가 발생했습니다.")
except MyCustomError as error:
    print(error)
```

## Call Stack

함수 호출 정보를 저장하는 메모리 구조다. 가장 나중에 호출된 함수가 먼저 끝나는 `LIFO(Last In, First Out)` 방식이다.

```python
def first():
    second()

def second():
    print("실행")

first()  # first → second 호출 후 second부터 종료
```

- 함수가 호출되면 스택 프레임이 쌓인다.
- 함수가 종료되면 해당 프레임이 제거된다.

## requests

`requests`는 파이썬에서 HTTP 요청을 보낼 때 사용하는 라이브러리다.

```bash
pip install requests
```

```python
import requests

response = requests.get("https://example.com")
print(response.status_code)
print(response.text)
```

자주 사용하는 HTTP 메서드:

- `requests.get(url)`: 데이터 조회
- `requests.post(url, data=...)`: 데이터 전송
- `requests.put(url, data=...)`: 데이터 수정
- `requests.delete(url)`: 데이터 삭제

### raise_for_status()

응답 상태 코드가 4xx 또는 5xx이면 `HTTPError`를 발생시킨다. 요청이 성공했는지 확인할 때 사용한다.

```python
import requests

response = requests.get("https://example.com")
response.raise_for_status()
data = response.json()
```

네트워크 오류까지 처리하려면 `try-except`와 함께 사용한다.

```python
try:
    response = requests.get("https://example.com", timeout=5)
    response.raise_for_status()
except requests.exceptions.RequestException as error:
    print(f"요청 실패: {error}")
```

## 파이썬에서의 환경 변수

환경변수는 소스 코드와 분리해 설정값이나 비밀번호·API 키를 관리하는 방법이다.

- 개발·테스트·운영 환경마다 다른 값을 사용할 수 있다.
- 설정을 바꿀 때 코드를 수정하지 않아도 된다.
- 비밀번호와 API 키를 코드에 직접 적지 않아도 된다.

### `os` 모듈로 환경변수 사용하기

```python
import os

# 환경변수 설정
os.environ["SERVICE_KEY"] = "abcd1234"

# 값이 없으면 KeyError 발생
service_key = os.environ["SERVICE_KEY"]

# 값이 없으면 None 반환, 기본값 지정 가능
db_host = os.getenv("DB_HOST", "localhost")
```

### `.env` 파일과 `python-dotenv`

`.env` 파일에 환경변수를 적고 `python-dotenv`로 불러올 수 있다.

```bash
pip install python-dotenv
```

```dotenv
DEBUG=True
SECRET_KEY=비밀키
PORT=8000
```

```python
import os
from dotenv import load_dotenv

load_dotenv()

debug = os.getenv("DEBUG")
secret_key = os.getenv("SECRET_KEY")
port = os.getenv("PORT")
```

### 보안 및 Git 관리

- `.env` 파일은 프로젝트 루트에 둔다.
- 비밀번호나 API 키가 있는 `.env`는 원격 저장소에 올리지 않는다.
- `.gitignore`에 `.env` 파일을 등록한다.

```gitignore
.env
.env.local
.env.*.local
```

환경변수는 기본적으로 문자열로 읽히므로 숫자나 불리언으로 사용할 때는 형 변환이 필요하다.

## lambda(익명 함수)

`lambda`는 이름 없이 한 줄로 작성하는 함수다. 간단한 연산이나 기준을 짧게 표현할 때 사용한다.

```python
add = lambda x, y: x + y
print(add(2, 3))  # 5
```

`map`, `filter`, `sorted`와 함께 변환식이나 정렬 기준을 작성할 때 자주 사용한다.

```python
numbers = [1, 2, 3, 4]
squares = list(map(lambda number: number ** 2, numbers))
even_numbers = list(filter(lambda number: number % 2 == 0, numbers))
```

복잡한 로직은 가독성을 위해 `def`로 이름 있는 함수를 작성하는 편이 좋다.

## 핵심 요약

- 예외는 `try-except`로 처리하고, `else`와 `finally`로 실행 흐름을 제어한다.
- 함수 호출은 Call Stack에 `LIFO` 방식으로 쌓인다.
- `requests`로 API를 호출하고 `raise_for_status()`로 HTTP 오류를 확인한다.
- API 키는 환경변수로 관리한다.
- `lambda`는 간단한 데이터 변환이나 정렬 기준에 사용한다.
