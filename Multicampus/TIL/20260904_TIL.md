## RAG 평가

정리 문서: [RAG 평가 상세 정리](../AI/rag_evaluation.md#rag-평가)

RAG는 검색 품질과 답변 품질을 나누어 평가한다.

```text
질문·정답 데이터 준비
→ 검색 전략 실행
→ 검색 지표 측정
→ 답변 생성
→ 근거성·관련성·정확성 평가
```

### 검색 평가

- **Hit@k**: 상위 `k`개 안에 정답 문서가 있는지
- **Precision@k**: 상위 `k`개 중 관련 문서 비율
- **Recall@k**: 필요한 정답 문서 중 찾은 비율
- **MRR**: 정답 문서가 검색 결과 앞에 나오는 정도
- **latency**: 검색에 걸린 시간

Similarity, MMR, BM25, Hybrid를 같은 평가셋과 후보 개수로 비교한다. 전체 평균뿐 아니라 질문 난이도별 결과와 `Recall@k`가 낮은 실패 사례도 확인한다.

### 답변 평가

검색된 문서로 답변을 만든 뒤 다음을 확인한다.

- 인용한 출처가 실제 검색 결과에 포함되는가
- 정답 문서를 인용했는가
- 답변이 검색 문서에 근거하는가
- 질문에 직접 답했는가

### RAGAS와 LLM-as-Judge

- **RAGAS**: Faithfulness, Answer Relevancy 등 범용 지표 사용
- **LLM-as-Judge**: 정확성, 완전성, 근거성, 출처 정확성 등 도메인 기준을 직접 정의

검색 지표는 비용이 낮아 자주 실행하고, RAGAS와 Judge는 대표 문항부터 실행한다. 품질 점수만 보지 말고 latency와 비용도 함께 비교한다.
