## Gemini Streaming

응답을 한 번에 받지 않고 여러 조각으로 받아 바로 출력하는 방식.
`stream=True`를 사용한다.

```python
stream = client.interactions.create(
    model=model,
    input="AI Agent를 설명해줘.",
    stream=True,
    store=False,
)

text_parts = []
for event in stream:
    if event.event_type == "step.delta":
        delta = getattr(event, "delta", None)
        if getattr(delta, "type", None) == "text":
            text = getattr(delta, "text", "")
            text_parts.append(text)
            print(text, end="", flush=True)

full_text = "".join(text_parts)
```

- SSE 방식으로 서버와 연결 유지
- 응답을 받는 즉시 출력 가능
- 긴 답변이나 실시간 응답에 적합

## Function Calling

Function Calling은 모델이 필요한 함수를 선택하고 이름과 인자를 전달하는 방식이다.
Python 함수 실행은 애플리케이션에서 직접 한다.

### 1. 함수 작성

```python
def get_product(product_id: str) -> dict:
    product = PRODUCTS.get(product_id.upper())
    if product is None:
        return {"ok": False, "error": "상품을 찾을 수 없습니다."}
    return {"ok": True, "product_id": product_id, **product}
```

### 2. 도구 schema 작성

모델이 함수의 이름, 설명, 인자 형식을 알 수 있도록 schema를 만든다.

```python
get_product_tool = {
    "type": "function",
    "name": "get_product",
    "description": "상품 ID로 상품 정보와 재고를 조회합니다.",
    "parameters": {
        "type": "object",
        "properties": {
            "product_id": {"type": "string"}
        },
        "required": ["product_id"],
    },
}
```

### 3. 함수 실행 결과 전달

모델이 반환한 `function_call`을 확인하고 등록된 함수만 실행한다.
그 결과를 `function_result`로 다시 모델에 전달하면 최종 답변을 만든다.

```python
TOOL_FUNCTIONS = {"get_product": get_product}

tool_result = TOOL_FUNCTIONS[function_call.name](
    **function_call.arguments
)

function_result = {
    "type": "function_result",
    "name": function_call.name,
    "call_id": function_call.id,
    "result": [{
        "type": "text",
        "text": json.dumps(tool_result, ensure_ascii=False),
    }],
}

final = client.interactions.create(
    model=model,
    input=[function_result],
    tools=[get_product_tool],
    previous_interaction_id=interaction.id,
    store=True,
)
```

### 여러 도구와 Agent loop

여러 함수를 `tools`에 등록하면 모델이 질문에 맞는 도구를 선택한다.
한 번의 요청에 `function_call`이 여러 개 나올 수도 있다.

일반적인 흐름:

`사용자 질문 → function_call → 함수 실행 → function_result 전달 → 최종 답변`

도구 호출을 반복할 때는 최대 반복 횟수를 정한다. 무한 호출로 인한 비용과 지연을 막기 위해서다.

## Built-in Tools

Gemini가 제공하는 도구. 개발자가 함수를 직접 실행하지 않아도 된다.

### Code Execution

Gemini가 Python 코드를 만들고 실행한다.

```python
interaction = client.interactions.create(
    model=model,
    input="1부터 100까지 3의 배수 합을 계산해줘.",
    tools=[{"type": "code_execution"}],
)
```

### Google Search

최신 정보가 필요할 때 검색 결과를 이용한다.

```python
interaction = client.interactions.create(
    model=model,
    input="오늘 서울 날씨를 알려줘.",
    tools=[
        {"type": "google_search", "search_types": ["web_search"]}
    ],
)
```

검색 출처는 모델 출력의 `annotations`에서 확인할 수 있다.
여러 내장 도구를 한 요청에 함께 등록할 수도 있다.

## 내장 도구와 사용자 정의 도구 비교

| 구분 | 내장 도구 | 사용자 정의 도구 |
|---|---|---|
| 제공자 | Google | 개발자 |
| 실행 위치 | Gemini 서버 | 애플리케이션 |
| 예시 | 검색, 코드 실행 | 주문 조회, 재고 확인 |
| 결과 처리 | Gemini가 자동 처리 | `function_result`를 직접 전달 |
