## Class(클래스)

객체를 만들 때 쓰는 설계도. 데이터는 속성, 동작은 메서드로 작성.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f"이름은 {self.name}, 나이는 {self.age}세입니다.")

person = Person("김철수", 25)
person.introduce()
```

### 정리

- **인스턴스**: 클래스로 만든 객체. `Person("김철수", 25)`
- **`__init__`**: 객체 생성 시 자동 실행
- **`self`**: 현재 객체
- **인스턴스 변수**: 객체마다 따로 저장
- **인스턴스 메서드**: 객체의 데이터를 다루는 함수
- **클래스 변수**: 모든 객체가 공유

```python
class Person:
    population = 0  # 클래스 변수

    def __init__(self, name):
        self.name = name
        Person.population += 1
```

### 매직 메서드

특정 상황에서 파이썬이 자동으로 부르는 메서드.

- `__str__`: `print(객체)`의 문자열 표현
- `__len__`: `len(객체)`의 반환값
- `__eq__`: `==` 비교 기준
- `__lt__`: `<` 비교 기준
- `__del__`: 객체가 삭제되기 전 정리 작업

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return self.name

    def __eq__(self, other):
        return self.age == other.age
```

## 클래스 속성 및 메서드

데코레이터로 메서드의 동작을 바꿀 수 있다.

### `property`와 `setter`

- `@property`: 메서드를 변수처럼 호출
- `@속성.setter`: 값 저장 전에 검사

```python
class Person:
    def __init__(self, age):
        self._age = age

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if value >= 0:
            self._age = value
```

### 클래스 메서드

`@classmethod`: 첫 번째 인자로 클래스(`cls`)를 받음. 클래스 변수에 사용.

### 정적 메서드

`@staticmethod`: `self`, `cls` 없이 동작하는 메서드.

```python
class Person:
    @staticmethod
    def is_adult(age):
        return age >= 19

print(Person.is_adult(20))
```

## 데코레이터와 고차 함수

### 데코레이터

기존 함수는 그대로 두고 기능을 덧붙이는 함수. `@데코레이터명`으로 적용.

```python
def trace_log(func):
    def wrapper(*args, **kwargs):
        print(f"{func.__name__} 호출")
        return func(*args, **kwargs)
    return wrapper

@trace_log
def greet():
    print("안녕하세요")

greet()
```

### 고차 함수

함수를 인자로 받거나 함수로 반환하는 함수.

```python
def execute(activity):
    return activity()

def run():
    return "달립니다."

print(execute(run))
```

### 일급 객체

파이썬에서 함수는 값처럼 다룰 수 있다.

- 변수에 할당
- 함수의 인자로 전달
- 함수의 반환값으로 사용
- 리스트나 딕셔너리에 저장

## 클래스 상속

부모 클래스의 속성과 메서드를 자식 클래스가 물려받는 기능.

### 단일 상속

```python
class Person:
    def __init__(self, name):
        self.name = name

    def walk(self):
        print(f"{self.name}이 걷습니다.")

class Student(Person):
    def study(self):
        print(f"{self.name}이 공부합니다.")

student = Student("김철수")
student.walk()   # 부모 메서드
student.study()  # 자식 메서드
```

### 메서드 오버라이딩

자식 클래스에서 같은 이름으로 다시 작성해 동작을 바꾼다.

### `super()`

부모 클래스의 생성자나 메서드를 호출할 때 사용. 부모 기능에 자식 기능을 더할 수 있다.

```python
class Developer(Person):
    def __init__(self, name, language):
        super().__init__(name)
        self.language = language
```

### 다중 상속과 MRO

- **다중 상속**: 여러 부모 클래스를 상속
- **MRO**: 메서드를 찾는 순서
- `클래스.mro()`로 순서 확인
