## 집합(Set)

```python
numbers = {10, 20, 30, 40, 50, 10}

print(numbers) # {50, 20, 40, 10, 30} -> 중복된 값 제외. 순서 없이 출력
```

- 0개 이상의 원소
- 중복 허용하지 않음
- 순서 없음
- 중괄호(`{}`) 사용
- hash라는 방식으로 저장됨
- 기본 자료형과 변경 불가능한 컨테이너만 허용
- 멤버십 연산(`in`, `not in`) 가능

## 집합 연산

### 교집합(`&`)

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a & b) # {3}
```

- 두 집합에 공통으로 존재하는 원소를 담은 집합을 생성

### 합집합(`|`)

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b) # {1, 2, 3, 4, 5}
```

### 차집합(`-`)

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a - b)  # {1, 2}
print(b - a)  # {4, 5}
```

- 왼쪽 집합에만 존재하는 원소를 담은 집합을 생성

## 딕셔너리(Dictonary)

```python
students = {"kyle": 10, "alex": 20}

print(students) # {'kyle': 10, 'alex': 20}
```

- 키(`key`)와 밸류(`value`)의 쌍을 순서 없이 저장하는 자료형
- 중괄호(`{}`)를 이용해 생성
- 각 키와 밸류 쌍은 콤마(`,`)로 구분
- 딕셔너리의 키는 기본 자료형과 변경 불가능한 컨테이너만 허용
- 키의 중복을 허용하지 않음
- 멤버십 연산(`in`, `not in`) 가능

### 자주 사용하는 메서드

- `get()`: 키를 통해 밸류를 가져온다.(단, 없는 키를 넣으면 기본 None을 받아오고, None일 경우 값을 지정할 수 있디/ - students.get("a", 0))
- `keys()`: 모든 키 목록
- `values()`: 모든 밸류 목록
- `items()`: 모든 키-밸류 쌍 목록
