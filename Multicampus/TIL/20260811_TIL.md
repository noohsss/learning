## 변수

- 데이터의 값을 저장하는 상자
- 할당 연산자(`=`)를 사용해 `변수 이름 = 값` 형식으로 작성
- 파이썬으로 변수명을 작성할 때는 보통 `snake case` 형식으로 작성한다.

```python
name = "Python"
age = 20
```

## List

- 여러 값을 순서대로 저장하는 자료형
- 대괄호(`[]`)를 사용하며 인덱스로 값에 접근한다.

```python
numbers = [1, 2, 3]
```

## Dictionary

- 키(key)와 값(value)을 한 쌍으로 저장하는 자료형
- 중괄호(`{}`)를 사용하며 키로 값에 접근한다.

```python
person = {"name": "Python", "age": 20}
```

## 자료형(Data Types)

- 자주 사용하는 자료형: 정수(`int`), 실수(`float`), 문자열(`str`), 불리언(`bool`)

### 타입 확인(type())

```python
type(10)  # int
```

### 명시적 형변환(Typecasting)

- 원하는 자료형을 직접 지정해 값을 변환한다.

```python
int("10")     # 10
str(10)       # "10"
float("1.5")  # 1.5
```

## 연산자(Operators)

- 산술: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- 비교: `==`, `!=`, `>`, `<`, `>=`, `<=`
- 논리: `and`, `or`, `not`

## Escape Sequence

- 문자열 안에서 특수한 기능을 표현하는 문자 조합
- `\n`: 줄바꿈, `\t`: 탭, `\\`: 백슬래시, `\"`: 큰따옴표

## 입력(input)

- 사용자 입력을 문자열로 반환한다.

```python
name = input("이름: ")
```

## 출력(print)

- 값을 화면에 출력한다.

```python
print("안녕하세요") # 안녕하세요

a = 10
print(a) # 10
```

## 조건문(Condition)

- 조건이 참인지에 따라 실행할 코드를 결정한다.

```python
if age >= 20:
    print("성인")
else:
    print("미성년자")
```

## 오늘 배운 내장함수 및 문법

- `type()`: 자료형 확인
- `int()`, `float()`, `str()`, `bool()`: 형 변환
- `input()`: 사용자 입력
- `print()`: 값 출력
