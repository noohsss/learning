## 함수(fucntion)

```python
def 함수명(매개변수):
    함수에서 실행되는 동작 1
    함수에서 실행되는 동작 2
    ...
    return 반환값
```

- 입력(`input`)을 넣었을 때 어떠한 출력(`output`)을 반환
- python 함수는 `def` 키워드로 생성한다.
- 함수를 사용하는 이유:
  - 코드의 재사용성, 가독성, 유지보수

### 함수의 구성

- 매개변수(`parameter`): 입력값을 받는 변수
- 인자(`argument`): 함수 호출 시 넘기는 실제 값
- 반환값(`return`):

## 모듈(module)

```python
import math

number = math.ceil(3.2)
```

- 특정 기능을 하는 코드를 파이썬 파일(`.py) 단위로 작성한 것
- `import`를 사용해 해당 모듈을 불러온다.

### 자주 사용하는 모듈

- `math`: 수학 연산 기능
- `random`: 난수를 다루는 기능
- `collections`: 특수한 용도의 컨테이너 자료형 제공 - 알고리즘에 많이 쓰임

## Python에서의 switch-case(match-case)

```python
number = 2

match number:
    case 1:
        print("하나")
    case 2:
        print("둘")
    case _: # 타언어의 default와 같음
        print("기타")
```

## 오늘 배운 내장함수 및 문법

- `def`: 함수를 생성하는 키워드
- `abs()`: 절대값
- `sum()`: 합계
- `min()`: 최소값
- `max()`: 최대값
- `sorted()`: 정렬(기본 오름차순, 내림차순 정렬 - `reverse=True` 옵션 추가)
- `map()`: 각 원소에 함수 적용
