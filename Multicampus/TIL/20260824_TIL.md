## 다형성(Polymorphism)

같은 이름의 메서드를 클래스마다 다르게 구현하는 것.
호출하는 쪽은 객체의 종류를 몰라도 같은 메서드를 호출하면 된다.

```python
class Person:
    def perform_role(self):
        pass

class Student(Person):
    def perform_role(self):
        return "학습을 수행합니다."

class Teacher(Person):
    def perform_role(self):
        return "강의를 수행합니다."

people = [Student(), Teacher()]
for person in people:
    print(person.perform_role())
```

### 추상 클래스

자식 클래스가 꼭 구현해야 하는 메서드를 정해두는 클래스.
`ABC`, `@abstractmethod` 사용. 구현하지 않으면 객체 생성 불가.

```python
from abc import ABC, abstractmethod

class Person(ABC):
    @abstractmethod
    def work(self):
        pass
```

## 클래스 Composition

필요한 객체를 속성으로 넣어 기능을 조합하는 방식.
상속은 **Is-A**, Composition은 **Has-A** 관계.

```python
class Engine:
    def start(self):
        return "엔진이 가동됩니다."

class Car:
    def __init__(self):
        self.engine = Engine()

    def drive(self):
        return self.engine.start()
```

객체를 외부에서 주입하면 부품 교체가 쉽다. 결합도도 낮아진다.

## Duck Typing

객체의 타입보다 필요한 메서드가 있는지를 보고 사용하는 방식.
오리처럼 걷고 울면 오리로 보는 것.

```python
class Dog:
    def speak(self):
        return "멍멍"

class Cat:
    def speak(self):
        return "야옹"

def make_sound(animal):
    print(animal.speak())
```

## Type Hint

변수, 매개변수, 반환값의 타입을 표시하는 문법.
실행 중 타입을 강제하지는 않음. 가독성과 자동 완성에 도움.

```python
def add(a: int, b: int) -> int:
    return a + b

name: str = "홍길동"
```

## Doc String

함수나 클래스 설명을 적는 문자열.
`help()`나 IDE에서 확인 가능.

```python
def greet(name: str) -> str:
    """이름을 받아 인사말을 반환한다."""
    return f"안녕하세요, {name}님"
```

## 객체지향 프로그래밍(OOP)

데이터와 기능을 객체로 묶어 프로그램을 만드는 방식.

- **캡슐화**: 데이터와 메서드를 묶고 내부 상태를 보호
- **상속**: 기존 클래스의 기능을 물려받아 재사용
- **추상화**: 복잡한 구현은 숨기고 필요한 기능만 제공
- **다형성**: 같은 메서드 호출이 객체에 따라 다르게 동작
