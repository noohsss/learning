# RAG Golden Set

Golden Set은 RAG 평가의 기준이 되는 질문, 기준 답변, 원문 근거를 묶어 둔 평가 사례 모음이다. 실제 RAG의 생성 결과가 아니라 원문을 검수해 확정한 기준을 사용한다.

## 작성 흐름

```text
평가 범위 결정 → 원문·버전 확인 → 질문·기준 답변 작성 → 근거 검수 → 버전 관리
```

평가 대상 문서와 버전을 먼저 정해야 한다. 답변 가능한 질문의 근거는 해당 문서 모음 안에 있어야 하며, 문서 버전이 달라지면 같은 질문이라도 기준 답변과 근거가 달라질 수 있다.

## 문항 구성 요소

| 항목 | 의미 |
|---|---|
| 질문 | RAG에 전달할 사용자 질문 |
| 기준 답변 | 반드시 포함되어야 할 핵심 내용과 조건 |
| 관련 문서 | 답변에 필요한 문서 ID·파일명·URL |
| 근거 구절 | 기준 답변을 뒷받침하는 원문 인용 |
| 근거 위치 | 페이지·절·조항·문단 등 원문 위치 |
| 답변 가능 여부 | 전체 원문으로 답변할 수 있는지 여부 |
| 질문 유형 | 사실 확인·조건 비교·답변 불가 등 |

필요에 따라 근거 형태, 난이도, 복수 출처 필요 여부, 관련성 점수, 문항 ID와 평가셋 버전을 추가할 수 있다. 필드 이름과 저장 형식은 사용하는 평가 도구와 맞춘다.

## 기준 답변 작성

기준 답변은 정답 문장을 그대로 지정하기보다 반드시 포함되어야 하는 사실과 조건을 정의한다. 표현이 달라도 핵심 내용과 원문의 조건이 유지되면 통과할 수 있도록 구성한다.

- 질문만 읽어도 의도를 이해할 수 있어야 한다.
- 질문에 정답을 그대로 포함하지 않는다.
- 수치·조건·예외를 원문과 일치하게 작성한다.
- 원문에 없는 내용을 기준 답변에 추가하지 않는다.
- 사실 확인, 조건 비교, 복수 근거, 유사 용어 구분 문항을 섞는다.

## 근거 관리

근거는 기준 답변을 뒷받침하는 원문 구절을 그대로 기록한다. 근거 구절이 문서에 존재하는지와 실제로 답변의 모든 조건을 뒷받침하는지는 별도로 검수한다.

문서 ID와 근거 위치를 저장하면 청크 크기를 바꾸거나 검색기를 변경해도 같은 원문 근거를 추적할 수 있다. 청크 ID를 기준으로 삼을 수도 있지만 재청킹할 때 ID가 달라질 수 있으므로 평가셋 갱신이 필요하다.

## 답변 불가 문항

답변 가능 여부는 검색된 일부 청크가 아니라 평가 대상 원문 전체를 기준으로 판단한다. 검색 실패와 원문에 정보가 없는 경우를 구분해야 한다.

답변 불가 문항에는 다음을 명시한다.

- 관련 문서 목록: 없는 경우 빈 목록
- 근거 구절: 없는 경우 빈 목록
- 기대 응답: 제공된 문서로 확인할 수 없다는 안내

RAG가 없는 사실을 추측하거나 답변 가능한 것처럼 말하지 않는지도 별도로 평가한다. 관련 문서가 없는 문항은 Recall@k 같은 문서 검색 지표의 분모에서 제외될 수 있으므로 제외된 수를 기록한다.

## 자동 생성과 검수

LLM으로 질문·기준 답변·근거 초안을 만들 수 있지만, 생성 결과를 그대로 Golden Set에 사용하지 않는다. 원문 대조와 사람 검수를 거쳐야 한다.

- 자동 검사: 필수 필드 누락, ID·질문 중복, 출처 존재 여부, 근거 구절의 원문 포함 여부
- 사람 검수: 질문의 자연스러움, 답변의 정확성·완전성, 예외 누락, 의미상 중복

오류가 발견된 문항은 수정하거나 제외하고, 수정 후 다시 원문과 대조한다.

## 평가셋 분리와 버전 관리

- **개발셋**: 청크 크기, 검색 방식, Prompt를 바꾸며 반복 비교하는 문항
- **테스트셋**: 개선 과정에 사용하지 않고 최종 성능을 확인하는 문항

같은 문항만 반복해 개선하면 해당 문항에 과도하게 맞춰질 수 있다. 검수한 Golden Set은 JSON·JSONL 등으로 저장하고, 원문 버전과 평가셋 버전을 함께 관리한다. 질문·기준 답변·근거가 바뀌면 새 버전으로 기록한다.

## RAG 평가 연결

RAG 실행 후에는 실제 검색 문서·청크·출처·순위와 생성 답변을 기록한다. 이를 Golden Set의 관련 문서, 원문 근거, 기준 답변과 비교한다.

```text
Golden Set 기준                    RAG 실행 결과
관련 문서 ID·원문 근거       ↔      실제 검색 문서·청크·출처
기준 답변                   ↔      실제 생성 답변
```

Golden Set의 질문·정답 파일을 검색 대상 원문에 포함하면 안 된다. 같은 문서 버전의 Golden Set을 사용해야 검색 품질과 답변 품질을 공정하게 비교할 수 있다.
